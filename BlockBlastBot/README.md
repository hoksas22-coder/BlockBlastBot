# Block Blast Bot — AndroidIDE edition

Проект подготовлен для сборки прямо на Android-телефоне через AndroidIDE.

## 1. Установить AndroidIDE

AndroidIDE умеет открывать существующие Gradle-проекты и собирать debug APK на самом телефоне.

Официальная документация: https://docs.androidide.com/user/getting-started.html

> Важно: оригинальный AndroidIDE сейчас не поддерживается разработчиками, поэтому скачивай APK только из доверенного источника/официального GitHub или используй совместимый форк.

## 2. Подготовить инструменты

В AndroidIDE открой Terminal и выполни:

    pkg upg
    idesetup -c

Подтверди установку (`y`). Для проекта достаточно Android SDK с API 33 и JDK 17.

## 3. Открыть проект

1. Распакуй `BlockBlastBot-AndroidIDE.zip`.
2. В AndroidIDE выбери **Open existing project**.
3. Выбери папку `BlockBlastBot` — ту, внутри которой находятся `settings.gradle` и `app/`.
4. Дождись окончания Gradle Sync.

## 4. Собрать APK

Нажми **Run / Quick Run**. AndroidIDE выполнит `assembleDebug` и предложит установить APK.

Если нужен APK-файл без установки, он будет здесь:

    app/build/outputs/apk/debug/app-debug.apk

## 5. Запустить бота

1. Установи APK.
2. Открой `Block Blast Bot`.
3. Нажми **Открыть доступность**.
4. Включи сервис `Block Blast Bot`.
5. Открой Block Blast.
6. Вернись в приложение и нажми **START BOT**.
7. Для остановки используй **STOP**.

## Важно

Распознавание сейчас настроено под интерфейс со скриншота 921×2048 и поле 10×10. На другом разрешении масштабирование предусмотрено, но если игра использует другой интерфейс/масштаб, координаты и распознавание могут потребовать настройки.
